# Database Viewer Support Center

Help and answers for **Database Viewer: MDB & ACCDB** (AccessViewer) on iPhone, iPad, and Android.

## Contact

Email us any time at **[w4n9we1@gmail.com](mailto:w4n9we1@gmail.com)** — include your device model, OS version, and the file format you are working with so we can reproduce the issue faster.

## Frequently Asked Questions

### Which file formats can I open?

Microsoft Access (MDB, ACCDB — Jet 3/4/2007+), SQLite databases, Excel workbooks (XLSX), OpenDocument spreadsheets (ODS), dBase files (DBF, dBase III), CSV and TSV text tables, and SQL dump scripts (SQLite dialect).

### How do I open a file?

Tap **Open file** and pick your database from the Files app (iOS) or your file manager (Android). A health check runs automatically before the file opens, so you know right away whether anything is wrong.

### Can the app edit my original file?

No — and that is by design. Edits are made on a private working copy stored inside the app. Your original file is never modified; exports are always written to a new destination you choose.

### How do I get my files into the app?

- **iPhone / iPad:** use the Files picker, or enable app file sharing via Finder (macOS) and copy files into the app's Documents folder.
- **Android:** use the system file picker (SAF). Files in your Downloads or any cloud-backed folder work directly.

### I bought Pro. How do I restore it?

Open the app, go to **Files → Settings**, and use **Restore purchases** with the same Apple ID / Google account you purchased with. Purchases are managed through RevenueCat, so your Pro entitlement follows your account on both platforms.

### Will there be a subscription?

No. Pro is a single one-time purchase. Pay once, keep everything.

### Is my data sent anywhere?

No. Database files, health reports, query results, and exports are processed on your device. The app contains no account system. See the [Privacy Policy](../privacy/) for details on advertising and purchase processing.

### Why does a file fail to open?

The health check explains exactly what is wrong — unsupported format version, encoding problems, or damaged regions — and suggests next steps. If you believe a supported file is being rejected, email it to us (or describe its properties) and we will investigate.
