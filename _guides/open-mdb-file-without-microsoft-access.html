How to Open an MDB File Without Microsoft Access

An MDB file is a Microsoft Access database, but you don't need Microsoft Access to open one. On Android or iPhone, Database Viewer reads MDB files on-device with a native C engine — health check first, then your tables in a generous free preview, with export in one-time Pro. On Windows, Access remains the official desktop route.

What you need before you start

Just two things: your phone (Android 8.0+ or iPhone with iOS 17.0+) and the .mdb file itself — no PC, no Microsoft Access installation, no account. The file can stay where it already is, in Downloads, Google Drive, iCloud Drive or any folder your phone can reach.

How to open an MDB file without Microsoft Access

Database Viewer is an MDB viewer with its own native C engine, so none of the steps below involves a PC. The same on-device engine also reads ACCDB, the newer Access format — the MDB viewer guide and the ACCDB viewer guide cover both formats in detail.

  1. Install Database Viewer from Google Play (Android 8.0+) or the App Store (iOS 17.0+). It is free to start and opens MDB files along with ACCDB, SQLite, XLSX, DBF, CSV and more.
  2. Open your .mdb file in the app: tap Open file and pick your database. On Android, choose it from the system file picker — Downloads, Google Drive or any folder your file manager can reach. On iPhone, pick it from the Files app, including iCloud Drive and third-party locations.
  3. Read the automatic health check before browsing: it confirms what the file really is, whether it is readable, which encoding it uses, and where damaged regions are.
  4. Browse the tables with a generous free preview — columns, search, sorting and SQL queries, all on-device. Export to CSV or XLSX is part of Pro, a single one-time purchase.

When you want the data out of the file, the MDB to CSV guide walks through export step by step.

What the health check tells you

Every file gets a health check before you open it, and the report is part of the free tier. It tells you four things: what the file really is (MDB on Jet 3 or Jet 4, or something else entirely), whether it is readable, which encoding it uses, and where damaged regions are. The last one matters most for files that have travelled through old servers, borrowed USB drives or years of backups.

It is a diagnosis, not a silent repair: the report explains what it found and suggests what to do next, while your original file is never modified. If a table is unreadable, you see why instead of a blank screen.

Desktop options without Access

On a Windows PC, Microsoft Access remains the official desktop route for MDB files — if you already have it installed, opening the file there is the familiar path. This guide focuses on the phone workflow, where no Microsoft software is needed at all; for simply reading the data, a phone with Database Viewer is often the fastest option.

Why avoid online “MDB opener” sites

An online MDB viewer or converter works in a browser and sounds effortless, but all such tools share one structural property: they cannot read a byte of your database until the entire file has been uploaded to their server. Where that copy goes afterwards — who stores it, for how long, and who can reach it — is outside your control, and Access databases often contain business or personal records.

No. Database Viewer includes its own native C engine that reads MDB (Jet 3 and Jet 4) and ACCDB files directly on your phone. Microsoft Access, and any desktop software, is not required.

Is it free?

Free to start with a generous free preview: opening files, the health report and browsing your tables work without paying. Pro is a single one-time purchase that adds export, editing and more.

Does it work on both Android and iPhone?

Yes. Database Viewer is available on Google Play for Android (8.0+) and on the App Store for iPhone (iOS 17.0+), with the same native on-device engine on both platforms.

Is my database uploaded anywhere?

Never. Everything runs on-device: the file is read locally, nothing is uploaded to a server, and no account is required. The original file stays read-only.
