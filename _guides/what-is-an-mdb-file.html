What Is an MDB File?

An MDB file is a Microsoft Access database: a single file that holds all the tables, plus saved queries, indexes and relationships. It was the default Access format from Access 97 through Access 2003, built on the Jet engine, and was superseded by .accdb from Access 2007. MDB files still open today, even on a phone without Microsoft Access.

What is an MDB file?

An MDB file is the container Microsoft Access used for its databases through the 2003 edition. Everything a database needs lives in that one file: the tables with their columns and rows, the saved queries, the indexes that keep lookups fast, and the relationships that tie one table to another. Copy the file to another machine and the database travels with it — nothing else has to come along.

Under the hood the format belongs to the Microsoft Jet database engine: Jet 3 arrived with Access 97 and Jet 4 with Access 2000 through 2003, which is why MDB documentation usually names those two versions. The file is organized into fixed-size pages, and each record sits in a fixed-length slot on a page — a tidily mechanical design from a time when disk space was budgeted byte by byte. None of that matters for reading the data, but it explains why the format asks for a dedicated engine rather than a text editor.

What does MDB stand for?

The extension is a historical abbreviation for Microsoft Database. It follows the naming habit dBASE set in the early days of database software, when data files got terse three-letter extensions — .dbf for dBASE tables — and Access carried the pattern forward with .mdb, then .accdb a generation later. Read “.mdb” on a file as shorthand for a Microsoft database, which in practice means an Access database.

Where MDB files come from

Few MDB files are young. Most come from legacy business software built on Access in the 1990s and 2000s that still runs: inventory lists, membership records, order tracking. Others were simply never upgraded — a database saved in the older format stayed in it when Access moved on. And a large share are archives: years of exports, backups and hand-me-down files that outlive both the software and the colleagues who made them. That is why an MDB file can still surface in a download folder, an email attachment or a shared drive long after the last copy of Access was uninstalled.

MDB vs ACCDB

MDB and ACCDB are the same product in two generations. MDB is the Jet-era format and held the default slot from Access 97 through Access 2003; ACCDB took over as the default with Access 2007 and runs on the newer ACE engine, adding field types MDB does not carry, such as attachments and multi-value fields. Neither generation is dead: both remain everyday formats, and Database Viewer reads both on the same on-device engine — the MDB viewer guide and the ACCDB viewer guide cover each in detail.

Frequently asked questions

What does MDB stand for?

MDB is a historical abbreviation for Microsoft Database. The three-letter extension follows the naming tradition dBASE started in the early days of database software, and in practice an .mdb file is a Microsoft Access database from the Jet era.

Is MDB the same as ACCDB?

No. They are two generations of the same format: MDB is the older Jet-based format, the Access default from 97 through 2003, while ACCDB has been the default since Access 2007 and runs on the newer ACE engine. Both remain Access databases, and Database Viewer opens both.

Are MDB files still used?

Yes. Legacy business software, desktop databases that were never upgraded and years of archives keep MDB files in circulation, so they still arrive by email, download and shared drives — often long after the last copy of Access was uninstalled.
