Export Access Data to CSV or Excel — on Your Phone

Exporting Access data to CSV or Excel takes no Microsoft Access: open the database on your phone with nothing uploaded, export the tables you open as CSV, or bundle the whole database into a sheet-per-table XLSX workbook. The system save dialog decides where files land. Export is part of Pro, a one-time purchase; previewing on the free tier comes first.

What you need

One phone with Database Viewer on it and the database itself — a file ending in .mdb or .accdb, whose insides the MDB viewer guide describes in depth. There is no third item: no desktop software, no export website, and the same flow covers an MDB export and an ACCDB export alike.

Opening these files on a phone is its own walkthrough: see how to open an MDB file without Microsoft Access if that half of the flow is new to you.

How to export Access data on your phone

An Access database export needs no desktop software — each step below happens in one app on your phone:

  1. Install Database Viewer from Google Play on an Android 8.0+ phone, or from the App Store on an iPhone running iOS 17 or later. Opening databases in it costs nothing.
  2. Open your database — tap Open file, then pick your .mdb or .accdb through the phone's own picker: on Android it opens Downloads, Google Drive and the rest of your storage locations; on iPhone the Files app covers local folders and iCloud Drive alike.
  3. Read the health check that appears before any table loads: it confirms the database is readable, names its text encoding and flags damaged regions — a diagnosis, not a repair — so the export starts from data you have seen verified.
  4. Export to CSV or XLSX: tap Export and choose the output. Table data writes the selected table as a CSV file; the XLSX workbook choice saves every table of the database into one Excel file, a sheet per table. The system save dialog then asks where the file should go. Export is part of Pro, a one-time purchase; you can preview the tables on the free tier first, so nothing is paid before the data has been checked.

Need CSV for every table rather than one? A ZIP choice in the same Export screen wraps each table's CSV into a single archive. The Database Viewer page lists what else the app opens beyond Access files.

CSV or Excel: which to pick?

Both come out of the same Export screen, so the choice is about destination, not capability. Pick CSV to move one table somewhere else; pick XLSX to export Access to Excel as one ready workbook.

Export as CSV

One table, one plain-text file with a header row on top. Practically anything that stores tabular data — spreadsheets, databases, scripts, web tools — accepts it, which makes CSV the format for feeding records into another system.

Export as Excel (XLSX)

Every table travels in one workbook, one sheet per table, in the format Excel opens natively. The pick when the point is a file people will simply open and look through.

For the CSV side in more depth — the format itself, its quirks and how a conversion behaves — the MDB to CSV guide goes further.

What carries over — and what doesn't

There is more inside an Access file than the values themselves, and an export carries only those values — so it helps to see which parts travel before you commit to a format.

What lands in the export

Every value you browsed, written out in plain characters — numbers, text and dates alike. A header row names the columns at the top, and the columns keep their original order underneath.

What stays in Access

Access-only machinery has no flat-file home and is left out: saved queries, table relationships, forms and reports. Binary and attachment columns still show up, and their cell contents come through as base64 text rather than the original binary files.

Your original file stays untouched

Exporting only reads. Database Viewer opens your database through a private read-only copy, the export passes over that copy, and every byte it writes goes into the new CSV, XLSX or ZIP — so the MDB or ACCDB you started with keeps every byte it had.

Frequently asked questions

Can I export Access data without Microsoft Access?

Yes, easily. Database Viewer carries its own native engine and reads MDB and ACCDB directly on the phone, so no copy of Access, no Windows machine and no converter website takes part. Open the file, choose the table you need and save it out as CSV — or take the whole database in one XLSX workbook.

Can I export the whole database at once?

Yes, two ways. The XLSX option writes every table into a single Excel file, each on its own sheet. If CSV is the target, the ZIP choice bundles a CSV per table into one archive, so nothing has to be exported by hand.

Should I pick CSV or XLSX?

Follow the destination. CSV is the plain-text route for moving one table into something else — a different database, a script or any tool that imports data. XLSX is the way to export Access to Excel itself: one workbook, one sheet per table, ready to open and read with no import step.

Is exporting free?

Browsing is. The free tier opens the database and shows every table in a generous preview at no cost, so you can confirm the data before unlocking anything. Export itself belongs to Pro, a single one-time purchase.

Is my data uploaded anywhere?

Never. The export runs entirely on the phone: the app's own engine decodes the database locally, and the finished CSV, XLSX or ZIP is written to wherever the system save dialog points. No account exists in the flow and no server sees a byte.

Will exporting change my original file?

No, and it never will. Database Viewer works from a read-only copy of your file, the export only reads through that copy, and all writing goes to the new CSV, XLSX or ZIP you create. The Access database you started with never changes.
