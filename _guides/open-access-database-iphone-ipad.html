How to Open an Access Database on iPhone & iPad

Microsoft Access databases — MDB and ACCDB alike — open on an iPhone or iPad without Microsoft Access. Install Database Viewer from the App Store (iOS 17 or newer), pick the file from the Files app, and a native engine reads it on the device, health check first. iCloud Drive and third-party cloud locations work; nothing is uploaded.

Database Viewer for iPhone and iPad opens ten formats on-device — the two Access generations are highlighted here:

  • MDB
  • ACCDB
  • SQLite
  • CSV
  • TSV
  • XLSX

  • DBF

What you need

Just two things: an iPhone or iPad — iOS 17 or later on the phone — and the database file itself, typically ending in .mdb or .accdb. A computer never joins the process, no Microsoft software is needed anywhere along the way, and no account comes into it. The file most often arrives on the device one of these ways:

  • Saved to Files straight from an email attachment.
  • Synced into iCloud Drive from a computer.
  • Handed over with AirDrop from a Mac.
  • Kept in a cloud drive that appears as a location in Files.

On an Android phone the same job runs through that system's own picker; the companion guide to opening an Access database on Android covers that side.

How to open an Access database on iPhone or iPad

Whether the target is an MDB on the iPad or an ACCDB on the iPhone, the walkthrough below is the same. Database Viewer carries its engine inside the app, so the file never travels anywhere to be read; the MDB viewer guide explains the Jet-era format, and the ACCDB viewer guide covers what Access 2007 introduced.

  1. Install from the App Store: Database Viewer on an iPhone running iOS 17 or later — one listing covers the iPad too. Free to start, it opens Access databases alongside SQLite, Excel and more.
  2. Open your file from inside the app — tap Open file, then choose the .mdb or .accdb through the Files app on iPhone or iPad: from On My iPhone, from iCloud Drive, or from a cloud location you have added to Files.
  3. Read the automatic health check shown before any table: it reports what kind of file arrived, whether the data reads cleanly, which character encoding to expect, and where damaged areas sit.
  4. Browse the tables in the generous free preview — columns and values are there to read, and the health report stays within reach. Export to CSV or XLSX arrives with Pro, a single one-time purchase.

Getting the file onto your device

The Access file itself can come from anywhere — what matters is that it lands somewhere the Files app can see. Four routes cover most situations:

  • Email attachment

    In Mail, tap the attachment and choose Save to Files, then pick a folder — Downloads or On My iPhone both work. The copy now sits on the device and opens any time, even offline.

  • iCloud Drive

    Drop the database into iCloud Drive on a Mac — through the Finder — or upload it at iCloud.com from a Windows PC. Syncing is automatic, and the file waits under iCloud Drive in Files.

  • AirDrop

    With a Mac nearby, share the file over AirDrop and accept it on the iPhone or iPad; saving it into Files from the share sheet takes one more tap.

  • Third-party cloud drives

    Services such as OneDrive, Dropbox or Google Drive can be added as locations inside the Files app, and a database stored there opens the same way as a local one.

iPhone and iPad: same engine

It is one app for both devices: a single App Store listing serves the iPhone and the iPad, and the same native engine does the reading on each. A database behaves identically however big the screen — same health check, same tables, same free preview. On the iPad the extra space simply gives a wide table more room, in portrait or in landscape. The Database Viewer page lists every format the engine handles beyond Access.

Frequently asked questions

Do I need Microsoft Access?

No. Database Viewer carries its own engine and reads MDB and ACCDB files directly on the iPhone or iPad — Microsoft Access plays no part, and neither does a computer. Once the file is on the device, the app parses it entirely on its own.

Where do I get the file on my iPhone?

Into the Files app, by whichever route suits you: save an email attachment with Save to Files, let iCloud Drive sync it from a computer, receive it over AirDrop from a Mac, or reach it through a cloud drive added to Files. Database Viewer opens the file from any of those spots.

Does it work on iPad too?

Yes. One App Store listing covers both: install the app on the iPad and it reads databases with the same engine as on the iPhone — health check, tables and free preview included. The iPad's larger display, portrait or landscape, simply shows more of a wide table at once.

Is the app free?

Free to start with a generous free preview; Pro is a one-time purchase. Opening a file of any supported format, reading its health report and looking through the tables in the preview cost nothing. Pro then adds export and more.

Is my database uploaded?

Never. The engine lives inside the app, so decoding happens entirely on the device and the database's contents never leave your iPhone or iPad. No account is created at any point, and the original file is never written to.

What if the file won't open?

Begin with the health report: it names what the file really is, how far the data reads cleanly, which encoding it expects and where damaged areas sit, then suggests a next step. That is diagnosis plus advice — the check only reads your file and never touches it.
