What is a winmail.dat file?

When Outlook sends a message in TNEF format, it packs the body, attachments and calendar invites into a single winmail.dat file. Other mail clients see only that one unopenable file. Winmail Reader unwraps the package and gives you back the message text, the attachments and the calendar invitation.

How do I open winmail.dat on iPhone or iPad?

In Mail or Files, tap Share (or Open In) and choose Winmail Reader, or send the file over from another app's share sheet. Decoding happens instantly on your device.

Every format, explained.

winmail.dat and TNEF

Winmail.dat appears when someone sends mail from Microsoft Outlook with rich formatting switched on: Outlook packs the message body, attachments and calendar invitations into a single TNEF wrapper (Transport-Neutral Encapsulation Format), and every other client — including Apple's Mail — sees an opaque dat file it cannot open. If Outlook mail won't open on iPhone, a TNEF wrapper is the most common reason. Winmail Reader unpacks that wrapper on your device and hands you back the real text, the attachments and the calendar invite inside.

Single message files: MSG, OFT, EML and MHT

An MSG file is a message saved from Outlook on Windows; an OFT is an Outlook template; an EML is what you get when a message is exported from Gmail, Windows Live Mail, Thunderbird or Apple Mail; MHT (also written MHTML) is a web-archive snapshot of an email or page. Winmail Reader opens each one on iPhone and iPad, shows the headers and the attachment list, lets you extract and save attachments, or convert to PDF — and export the same message as EML, HTML or plain text.

Mailbox archives: MBOX, PST, OST and OLM

Mailboxes travel as archives too. Gmail Takeout hands you MBOX files; an Outlook export on Windows produces PST data files (and OST offline stores); Outlook for Mac produces OLM archives. Winmail Reader browses these mailbox backups as a folder tree and previews the newest message in every folder for free — and with Pro you can search inside email across the whole archive, so an old mailbox backup becomes something you can actually use.
