Every email format, one iPhone app

Winmail Reader opens eleven legacy email and document formats on iPhone and iPad — single messages, whole mailbox archives and Windows XPS documents. Everything is decoded on-device: no account, no uploads. Pick a format to see what it is and how to open it.

Single messages

winmail.dat / TNEF Outlook's TNEF wrapper — the message, its attachments and calendar invites in one file.
MSG / OFT A message or template saved from Outlook on Windows.
EML / EMLX The standard single-message file exported by most mail apps.
MHT / MHTML A saved web page or exported email thread.

Mailbox archives

MBOX Mailbox export, including Google Takeout and Thunderbird.
PST / OST Outlook data files and offline stores on Windows.
OLM Outlook for Mac archive.

Documents

XPS / OXPS Windows XML Paper Specification documents, read like PDFs.

Detailed guides for each format are being published here as they are finished — this page links to them as they go live. See the app.
