What is a PST file?

A PST file is Outlook's own database for mail on Windows. Mailboxes, folders, messages, calendar entries, contacts and their attachments all live inside one container with its own internal indexing — which is why a PST does not open in a text editor and why mail clients other than Outlook usually refuse it.

The container is built in layers: a low-level database holds the pages, and a higher-level layer describes the folder and message tables inside it. The file starts with a !BDN signature that identifies it as a PST or OST container, and Winmail Reader's decoder reads those layers directly rather than trying to import the file into a mail account.

PST, OST and where the file comes from

The two extensions hold the same kind of container. A PST is a data file: people archive an old mailbox into one, copy it to a drive, or export a colleague's mail for a handover. An OST is the offline cache Outlook keeps for an Exchange or IMAP account, so it is tied to that account and lives in the local Outlook data folder.

That difference matters most when something goes wrong: an OST can be left behind by a mailbox that was closed, and a PST is often the only surviving copy of an old archive. In both cases a reader that opens the container itself is enough to see what is inside — and because the file is opened as a copy, it is never modified while you read it.

How to open a PST file on iPhone or iPad

  1. Install Winmail Reader from the App Store (iOS 17.0+ / iPadOS 17.0+). It is free to look inside.
  2. Get the PST or OST file onto the device. Copy it into Files from a computer, a USB drive or iCloud Drive — usually the whole archive file, without unzipping anything.
  3. Open it with Winmail Reader. Tap the file in Files, or pick the app in the share sheet or in another app's Open in menu. The file check-up names what the container really is and how confident the detection is.
  4. Look at the folder tree, then unlock full browsing. The free tier shows the root folder area with a preview of the first messages; Pro unlocks every folder, opening any message in full, attachment preview and extraction, PDF, EML, HTML, TXT and RTF export, and search across the archive.

Online converter or on-device app?

A PST is usually the largest private file a person owns in email form: years of correspondence in one container, often including invoices and contracts. An online PST viewer has to receive that whole container before it can show a single folder name.

Online converter

The archive leaves your device before you see anything. Processing happens on a third-party server, and its retention policy is not something you control.

Winmail Reader — on-device

Decoding runs on your iPhone or iPad. Nothing is uploaded, no account is required, and the original file is opened read-only. Decoded copies stay in the app's sandbox until you delete them.

Frequently asked questions

What is a PST file?

A PST file is Outlook's data file on Windows: a single binary container holding folders, messages, calendar items, contacts and attachments. It is not a text format, so you cannot read it in a text editor. Internally it is built in layers, and the file starts with a !BDN signature that identifies it as a PST or OST container.

Can I open a PST file on iPhone or iPad without Outlook?

Yes. Winmail Reader decodes the PST container itself on the device, so no Outlook installation, no Exchange server and no account is involved. You can open the file from Files, from the share sheet, or from another app's Open in menu, and the app reads it as a copy without modifying the original.

What is the difference between PST and OST?

Both are Outlook data containers with the same internal structure. A PST is a data file you can save, copy and archive; an OST is the offline cache Outlook keeps while connected to an Exchange or IMAP mailbox, and it is tied to that account. Winmail Reader opens both the same way and treats them as read-only.

Does Winmail Reader convert a PST or OST file to something else?

It does not rewrite archives: there is no PST writer in the app, so PST and OST files are opened read-only for browsing. What you can do as part of Pro is export individual messages out of the archive to PDF, EML, HTML, TXT or RTF, and extract their attachments.

Is Winmail Reader free?

Free to look inside: open every supported format and see the sender, subject and first screen of any message, the attachment list, the folder tree of a mailbox archive with a preview of its first messages, and the first page of an XPS document. Full reading, attachment extraction, full archive browsing, exports, search and resending are part of Pro — a single one-time purchase. An optional monthly subscription is also available, priced as shown in the app.

How large a PST file can it open?

Archives of several gigabytes are handled: the app indexes the container and reads messages on demand instead of loading the whole file into memory, and a long scan can be cancelled. Damaged containers are the more common obstacle than size — the file check-up will tell you what the file really is and whether it looks incomplete, but it does not repair broken archives.
