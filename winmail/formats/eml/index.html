What is an EML file?

An EML file is one email message stored as a MIME document. It starts with the internet headers — From, To, Subject, Date, Message-ID — followed by the body, and it carries every attachment as a MIME part with its own filename and content type. Because the whole message is plain text, an EML file can be read in any text editor, which is why it is the export format most mail apps write when you choose "save as file".

Because it is an open standard, an EML file is not tied to a vendor: the same message can be exported by Apple Mail, Thunderbird, Outlook, Gmail or a ticketing system and still read the same way. What changes between them is only how faithfully the original body was stored — HTML, plain text, or both at once.

Why do people send EML files instead of forwarding?

A forwarded message loses its original headers, its recipients and often its attachment names. Saving the message as an EML file keeps the whole thing intact: the original sender and date stay in the headers, and the attachments keep their exact bytes. That is why EML is what shows up in support tickets, legal correspondence, migration exports and archive folders.

One detail matters on a phone. When the original message was composed in Outlook Rich Text Format, the attachments inside the EML are wrapped in a TNEF package — the same structure behind winmail.dat. A generic MIME reader only sees one anonymous part named winmail.dat. Winmail Reader decodes that nested package and lists the real files, so an EML exported from Outlook does not turn into a message with no attachments.

How to open an EML file on iPhone or iPad

  1. Install Winmail Reader from the App Store (iOS 17.0+ / iPadOS 17.0+). It is free to look inside.
  2. Get the file into Files or the share sheet. Save the attachment from Mail, a chat app or a web download to Files, then tap it — or tap Share and pick Winmail Reader. Files in iCloud Drive, Downloads or another app work the same way.
  3. Read the decoded message. The app shows the sender, subject and first screen of the message plus the attachment list. A file check-up explains what the file really is if detection is uncertain, since an .eml exported from a phone can just as easily be an MHTML page.
  4. Unlock full reading and export. Pro unlocks the complete message, attachment preview and extraction, PDF, EML, HTML, TXT and RTF export, and search inside the message. The purchase is one-time; an optional monthly subscription is also available.

An online EML viewer has to receive the whole message before it can show you a line of it — headers, recipients and attachments included. Business mail regularly contains invoices, contracts or client correspondence, and that copy then sits on someone else's server.

Frequently asked questions

What is an EML file?

An EML file is a single email message saved as a plain MIME text file — headers first, then the body and any attachments encoded inline. It is the format most mail apps use when you export a message or save it to disk, and it opens in any text editor because it is readable text rather than a proprietary container.

Can I open an EML file on iPhone or iPad?

Yes. Winmail Reader opens EML files on iPhone and iPad without Microsoft Outlook, Exchange or any mail account. Save the file to Files or pick Winmail Reader in the share sheet, and the message is decoded on your device.

Does an EML file keep its attachments?

Yes. Every attachment travels inside the same file, encoded as a MIME part with its own name and content type. Winmail Reader lists those parts, and if the original message was composed in Outlook Rich Text Format the nested TNEF package is decoded as well, so a winmail.dat inside an EML is shown as the real attachments.

What is the difference between EML and MSG?

EML is an open MIME text file: headers, body and attachments in plain text, readable by any mail app. MSG is Microsoft Outlook's binary container for the same idea, and it is not readable in a text editor. Winmail Reader opens both, so you can compare or convert them in one place.

Full reading, attachment extraction, full archive browsing, exports, search and resending are part of Pro — a single one-time purchase. An optional monthly subscription is also available, priced as shown in the app.

Can I convert an EML file to PDF on iPhone?

Yes. Exporting a message to PDF is part of Pro, together with EML, HTML, TXT and RTF export. In the free tier you can open the EML file and see the sender, subject, first screen of the message and the attachment list before unlocking.
