What is an OLM file?

An OLM file is a mailbox archive exported from Outlook for Mac. It holds the folders, messages, calendar items and contacts of that mailbox in one file — the Apple-side counterpart of a Windows PST, but built on a completely different container.

Where a PST is a binary database, an OLM is a ZIP archive. Open a copy of it (renaming it to .zip is enough) and you find the mail folders as directory paths, one XML file per message holding the subject, sender, recipients, dates, body and attachment list, and the original attachment files sitting in an attachment folder beside the messages that reference them. Inside Outlook's export, the messages live under a path such as com.microsoft.__Messages/<folder>/message_00001.xml, and every further path segment is another level of the folder tree. Because attachments are referenced by path rather than embedded in the message, a message and its attachments only make sense read together.

Why you have an OLM file, and what it needs

OLM files turn up in exactly the situations where the mailbox no longer exists: a contractor's old archive handed over at the end of a project, a colleague moving from a Mac to a Windows machine, a mailbox exported before an account was closed, or a backup kept because the mail contained the only copy of a contract. In each case the archive is what survives, and the mail app that created it is gone.

That is why a phone reader is often the fastest way in. Outlook on Windows cannot open an OLM file, and viewing one on a computer usually means either having Outlook for Mac again or unpacking the archive and reading raw XML. A reader that understands the container shows the folder tree and the messages themselves, with the attachment paths resolved back into real attachments.

How to open an OLM file on iPhone or iPad

  1. Install Winmail Reader from the App Store (iOS 17.0+ / iPadOS 17.0+). It is free to look inside.
  2. Copy the OLM file into Files from a computer, a USB drive or iCloud Drive. Keep the .olm file as it is — there is no need to rename it, unzip it or convert it first.
  3. Open it with Winmail Reader. Tap the file in Files, or choose the app in the share sheet or in another app's Open in menu. The file check-up confirms what the container is and how confident the detection is.
  4. Browse the folder tree, then unlock full browsing. The free tier shows the root folder area with a preview of the first messages; Pro unlocks every folder, opening messages in full, attachment preview and extraction, PDF, EML, HTML, TXT and RTF export, and search across the archive.

Online converter or on-device app?

A mailbox archive is one of the most private files a person keeps: years of correspondence, invoices and personal attachments in a single container. An online OLM viewer has to receive that whole file before it can show a single folder name.

Frequently asked questions

What is an OLM file?

An OLM file is a mailbox archive exported from Outlook for Mac. Unlike the Windows .pst container, it is a ZIP archive: the mail folders are stored as directory paths inside it, each message is a separate XML file, and the original attachments sit in an attachment folder next to the messages that reference them.

Can I open an OLM file on iPhone or iPad without Outlook?

Yes. Winmail Reader reads the archive's own structure on the device, so no Outlook installation, no mail account and no Exchange server is involved. You can open the file from Files, from the share sheet, or from another app's Open in menu, and the app works on a copy without modifying the original.

Is an OLM file just a ZIP archive I can rename?

The container is indeed a ZIP archive, and renaming a copy to .zip lets you unpick it on a computer. What you get is a tree of XML message files rather than readable mail, so you still need something that understands those XML records. Winmail Reader reads the archive directly, so you do not unpack anything to view a folder or a message.

Does Winmail Reader convert an OLM file to PST or back into Outlook?

No. The app has no archive writer, so an OLM file is opened read-only for browsing. What Pro adds is the ability to take content out of it: individual messages export to PDF, EML, HTML, TXT or RTF, and their attachments can be previewed and extracted.

Is Winmail Reader free?

Free to look inside: open every supported format and see the sender, subject and first screen of any message, the attachment list, the folder tree of a mailbox archive with a preview of its first messages, and the first page of an XPS document. Full reading, attachment extraction, full archive browsing, exports, search and resending are part of Pro — a single one-time purchase. An optional monthly subscription is also available, priced as shown in the app.

What if the OLM file will not open?

The file check-up runs first and tells you what the file really is and how confident the detection is. A truncated or damaged container is reported as such rather than as a decoding bug, and messages that cannot be parsed are skipped and counted, so the rest of the archive can still be browsed. The app does not repair broken archives.
