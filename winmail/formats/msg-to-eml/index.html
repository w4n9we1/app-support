Convert MSG to EML on iPhone

Converting MSG to EML turns an Outlook message file into the standard MIME format most mail apps can import. On iPhone or iPad, Winmail Reader reads the MSG on-device and writes an EML with the same headers, body and attachments — no Outlook, no Windows PC and nothing uploaded.

What actually changes when MSG becomes EML?

The container changes, the message does not. A MSG file is Microsoft's Outlook container: headers, body and attachments bundled in one compound file that only Outlook-family software reads. An EML file is a plain RFC 5322 message — text you can open, grep, archive or import anywhere.

So the conversion is a rewrite, not a re-typing. The subject, sender, recipients and date are written as standard header lines; the body is written as HTML and plain-text parts; each attachment becomes its own MIME part with its original file name. Non-ASCII subjects and file names are encoded the way the MIME standards require, and long header lines are folded, so another mail app reassembles the same message rather than a mangled one.

How to convert a MSG file to EML on iPhone or iPad

  1. Install Winmail Reader from the App Store (iOS 17.0+ / iPadOS 17.0+). It is free to look inside.
  2. Open the MSG file. In Mail or a chat app, save the attachment to Files, or tap Share and pick Winmail Reader. Files arriving through Files, iCloud Drive or another app work the same way.
  3. Check what the file holds. The app reads the Outlook container on-device and shows the sender, subject and first screen of the message, plus the attachment list. The file check-up explains the detection if the file is unusual or partly damaged.
  4. Export the message as EML. With Pro, open the message, choose EML in the export row, and the decoded message is written as a .eml file inside the app — from there, share it or save it to Files.

The same export row also offers PDF, HTML, TXT and RTF. Pick EML when the message has to stay re-importable; pick PDF when it has to look the same everywhere.

Online MSG to EML converter or on-device app?

A browser converter has to receive the entire message — body and attachments — before it can return an .eml, and that copy is processed on someone else's server. Both routes give you an EML; the difference is where the file was opened.

Online converter

The file leaves your device before you get any output. Conversion happens on a third-party server, and its retention policy is outside your control.

Winmail Reader — on-device

Reading the MSG and writing the EML both run on your iPhone or iPad. Nothing is uploaded, no account is required, and the original file stays read-only. The exported EML stays in the app's folder until you share or delete it.

Frequently asked questions

Can I convert a MSG file to EML on iPhone?

Yes. Winmail Reader reads the MSG container on your iPhone or iPad and writes a standard .eml file from it — no Outlook, no Windows PC and no upload. The conversion is one of the Pro actions; looking inside the message first is free.

Is MSG to EML conversion free?

No. Free to look inside: open the MSG file and see the sender, subject and first screen of the message, the attachment list, and the file check-up. Writing the message out as EML is part of Pro — a single one-time purchase. An optional monthly subscription is also available, priced as shown in the app.

Do attachments survive MSG to EML conversion?

Yes. The EML is written as a multipart message: the body becomes its own part and every attachment becomes a separate part with its original file name, so the receiving mail app shows the same files, not a flattened copy.

Will non-English subjects and file names survive the conversion?

Yes. Non-ASCII subject lines, display names and attachment file names are written with the standard MIME encodings (encoded-words for headers, RFC 2231 for file names), and long header lines are folded. The result reads back correctly in mail apps that follow those standards.

Can I open the exported EML in another mail app?

Yes. EML is the standard single-message file that most mail apps import, so the exported message can be dragged into Thunderbird, opened in Outlook, re-imported into another mailbox or archived as a plain file. It stays a normal MIME message, readable outside this app.

Are my files uploaded when converting MSG to EML?

No. Reading the MSG and writing the EML both happen on your iPhone or iPad: no account and no uploads. Your original MSG file is opened read-only, and the exported EML stays in the app's own folder until you share it or delete it.
