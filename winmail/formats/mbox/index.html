What is an MBOX file?

An MBOX file is a mailbox flattened into a single text document. Messages are appended one after another, and each one begins with a separator line starting with the word From followed by the sender and a date. Inside that boundary the message is ordinary MIME — headers, body, attachments — exactly what you would find in an EML file.

Because there is no index, no header block and no table of contents, an MBOX file is easy to write but harder to read: a reader has to walk the whole file to know how many messages it holds and where each one starts. That is also why a mailbox export is often split into several files rather than one giant document.

Where MBOX files come from

Google Takeout is the most common source on a phone: choosing Mail in a takeout produces a ZIP whose Takeout/Mail/ folder contains one .mbox file per Gmail label. Thunderbird stores each local folder as an MBOX file, and many backup or migration tools write MBOX because it survives being copied, archived and re-imported.

Two practical consequences matter on iOS. First, the export usually arrives as a ZIP, so the archive has to be unzipped in Files before any app can look at it — Winmail Reader opens the .mbox file, not the ZIP around it. Second, a real mailbox can be large — exports of several gigabytes exist — with bodies in mixed encodings and lines that begin with From quoted so they cannot be mistaken for a separator.

How to open an MBOX file on iPhone or iPad

  1. Install Winmail Reader from the App Store (iOS 17.0+ / iPadOS 17.0+). It is free to look inside.
  2. Unzip the export and pick the .mbox file. For a Google Takeout, unzip the download in Files and open the .mbox file inside it — Takeout usually writes one file per label. Thunderbird and other exports produce a .mbox file directly.
  3. Look at the archive on your device. The app shows the folder area and a preview of the first messages in the list, plus a file check-up that says what the file really is if detection is uncertain.
  4. Unlock full browsing and export. Pro unlocks browsing every folder, opening any message in full, attachment preview and extraction, PDF, EML, HTML, TXT and RTF export, and search across the archive. The purchase is one-time; an optional monthly subscription is also available.

Online converter or on-device app?

A whole-mailbox export is the most sensitive file in this family: it is not one message but years of correspondence, with invoices, contracts and personal mail in the same document. An online MBOX viewer has to receive that entire file — and any unzip-and-upload service too — before it can render a single row.

Online converter

The export leaves your device before you see anything. Processing happens on a third-party server, and its retention policy is not something you control.

Winmail Reader — on-device

Decoding runs on your iPhone or iPad. Nothing is uploaded, no account is required, and the original file is opened read-only. Decoded copies stay in the app's sandbox until you delete them.

Frequently asked questions

What is an MBOX file?

An MBOX file is a whole mailbox exported as one plain-text file: every message is concatenated into the same document and each one begins with a line starting with From. There is no index inside it, so a reader has to scan the file to separate one message from the next. Google Takeout, Thunderbird and several other mail tools export in this format.

How do I open a Gmail Takeout MBOX on iPhone or iPad?

Download the Takeout archive, unzip it in Files, then open the .mbox file with Winmail Reader — either by tapping the file or by choosing the app in the share sheet. Google splits a takeout into several .mbox files, usually one per label, and Winmail Reader opens them one at a time.

Can I open an MBOX file without a mail account?

Yes. Winmail Reader needs no account, no Exchange server and no mail login. The archive is decoded on your iPhone or iPad, so importing a mailbox export does not require pointing any mail client at it.

Does Winmail Reader show the folder structure of an archive?

A single MBOX file is flat, and a takeout usually writes one file per label, so the label is the file. When an archive holds several folders, Winmail Reader shows that tree: the free tier shows the root folder area with a preview of the first messages, while browsing beyond that first screen, opening rows, moving through non-root folders and searching across the archive are part of Pro.

Is Winmail Reader free?

Free to look inside: open every supported format and see the sender, subject and first screen of any message, the attachment list, the folder tree of a mailbox archive with a preview of its first messages, and the first page of an XPS document. Full reading, attachment extraction, full archive browsing, exports, search and resending are part of Pro — a single one-time purchase. An optional monthly subscription is also available, priced as shown in the app.

Can I get messages out of an MBOX archive on iPhone?

Yes, as part of Pro: open a message from the archive and export it to PDF, EML, HTML, TXT or RTF, or extract its attachments. There is no MBOX to PST conversion, because Winmail Reader has no PST writer — PST and OST files are opened read-only for browsing.
