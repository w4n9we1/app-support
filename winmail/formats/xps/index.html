What is an XPS file?

An XPS file is a fixed-layout document that describes its pages instead of storing a picture of them. Microsoft introduced the format with Windows Vista as a print-and-share alternative to PDF: text, vector graphics and images are recorded page by page, so a document looks identical on any device that can read it. The .oxps extension is the standardised version of the same format.

The container is an OPC package — a ZIP archive of XML parts, with a fixed-document sequence that names the pages, a page part for each page's content, and shared resources such as fonts and images beside it. That is why a file manager can rename an XPS to .zip and list its innards while showing nothing readable: the content only becomes a document when something renders those parts together. Winmail Reader does that rendering on the device.

Why an XPS file lands on your phone

XPS files arrive from exactly the places where a Windows program offers "print" or "save as document": bank statements, invoices, scanned contracts, a save-as-XPS from Word or Excel, a report generated by accounting software, or an email attachment a colleague produced on a Windows machine. The file is fine — the problem is the phone. iOS has no built-in XPS viewer, so Files shows a generic icon, a tap opens nothing useful, and the document looks broken when it is not.

Two things matter in that moment: seeing the first page quickly to know what the document is, and being able to read all of it when it turns out to be the contract you needed. That is how the free and paid layers are split here.

How to open an XPS file on iPhone or iPad

  1. Install Winmail Reader from the App Store (iOS 17.0+ / iPadOS 17.0+). It is free to look inside.
  2. Save the .xps or .oxps file into Files — from an email attachment, a download, iCloud Drive or a USB drive. Keep the file as it is; there is no need to convert it first.
  3. Open it with Winmail Reader. Tap the file in Files, or choose the app in the share sheet. The file check-up confirms what the document is and how confident the detection is.
  4. Read the first page, then unlock the document. The free tier renders page one at full width; Pro unlocks paging through every page, zoom, search with page jumps, and XPS to PDF export.

Frequently asked questions

What is an XPS file?

XPS (XML Paper Specification) is Microsoft's fixed-layout document format, introduced alongside Windows Vista. A file holds numbered pages with text, vector graphics and images, so it looks the same everywhere — the same job a PDF does. It is packaged as an OPC archive of XML parts rather than a single binary stream.

What is the difference between XPS and OXPS?

The .oxps extension is the Open XML Paper Specification, the standardised version of the same format with a different top-level content type. In practice both open the same way, and Winmail Reader accepts either extension for a document you already have.

Can I open an XPS file on iPhone or iPad?

Yes. iOS has no built-in XPS viewer, so the file usually arrives with no app willing to open it. Winmail Reader decodes the document on the device: the first page renders for free, and a one-time purchase unlocks paging, zoom, search with page jumps, and XPS to PDF export.

Is Winmail Reader free?

Free to look inside: open every supported format and see the first page of an XPS document, the sender, subject and first screen of any message, the attachment list, and the folder tree of a mailbox archive with a preview of its first messages. Full document reading, full message reading, attachment extraction, full archive browsing, PDF and format exports, search and resending are part of Pro — a single one-time purchase. An optional monthly subscription is also available, priced as shown in the app.

Does Winmail Reader convert XPS to PDF?

Yes. XPS to PDF export is part of Pro. The PDF is produced on the device from the decoded pages, so the document is never uploaded to a conversion server.

Can Winmail Reader edit an XPS document or turn it into Word?

No. XPS is a fixed-layout format: a viewer can render, search and export its pages but cannot reflow the content into an editable Word or Excel document, and this app does not claim to. It also does not repair a damaged document — the file check-up reports what the file really is and how confident the detection is.
