What is checked, exactly 
1. manifest.json — its own SHA-256 is compared with the value printed on the PDF's seal page or in the QR code (?h=…).
2. Every file listed in manifest.json — SHA-256 of the bytes you dropped, compared with the value in the manifest.
3. packageHash — one number over the whole file list: SHA-256 of every line "<file sha256>  <file path>" sorted by path.
4. hashes.txt — one line per record: "<sha256>  <record id>  <date UTC>". Each line must match the record's fingerprint in records.json.
5. Every record — the fingerprint is recomputed from the record's own fields and the fingerprint before it, so a single changed character in a date, note, place, status, factor or attachment hash breaks it.

A package is a record, not legal advice. Whether it is admitted is decided by a judge under the rules where you live.
