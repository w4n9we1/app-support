# Masked

**Safe Before AI**

Masked helps you find and clean sensitive information before sharing text, screenshots, and work files with ChatGPT, Claude, Gemini, Cursor, or another destination.

## Clean Complex Material On Your iPhone

- Review sensitive details detected in pasted text and long prompts.
- Scan screenshots with on-device text recognition and face detection.
- Process supported plain-text work files, including TXT, Markdown, LOG, JSON, CSV, source code, and configuration files.
- Review every detected area or value before creating the result.
- Clean multiple screenshots or work files in a batch.

Masked creates a new safe copy instead of intentionally overwriting the original. Image exports can also remove EXIF metadata according to your selected setting.

## Designed For Review, Not Blind Trust

Automatic detection can miss sensitive information or flag content that is not sensitive. Always review the selected masks, replacements, and exported copy before sharing it.

The current version does not clean PDF or Microsoft Office documents. Convert or export that content to a supported format before using Masked.

## Privacy By Design

Text detection, screenshot OCR, face detection, masking, replacement, metadata cleaning, and safe-copy generation are designed to run on your device. Masked does not upload the material you clean to a cloud scanning service.

For complete details, read the [Masked Privacy Policy](privacy/).

## Free-user advertising

Free users may see Google-served ads. Masked Pro does not load or request in-app ads. Advertising consent is requested through Google's certified consent flow where required. Ads do not receive the text, images, work files, filenames, or detected sensitive values that you clean in Masked.

## Support

**What should I include in a support request?**

Please include your Masked version, iOS version, a description of the issue, and a screenshot or screen recording when appropriate. Do not send unredacted sensitive material.

**Why did Masked miss or incorrectly select something?**

Detection results depend on the source image, text, language, and formatting. Use the review controls to include, skip, add, or edit detected content before generating a safe copy.

**Does Masked change my original file?**

Masked generates a separate safe copy. Keep your original until you have reviewed and saved the result you need.

**How do I restore Masked Pro?**

Open the Masked Pro screen in the app and use Restore Purchases with the Apple Account that made the original purchase.
