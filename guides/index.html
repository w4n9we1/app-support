Frequently asked questions

Are these guides free to read?

Yes — every guide on this page is free to read, no account needed. Database Viewer itself is free to start with a generous free preview; Pro is a one-time purchase.

Which formats does the app support?

Database Viewer opens ten formats on Android and iPhone: MDB and ACCDB (Microsoft Access), SQLite, DBF (dBase), ODS (OpenDocument spreadsheets), XLSX and XLSM (Excel workbooks), and CSV, TSV and SQL dump as plain-text data. The formats index links a guide for each.

Is my data uploaded?

No. Every file is read on the phone itself: nothing is sent to a server, no account is required, and the original file opens read-only.
