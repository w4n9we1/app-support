What is an MDB file?

MDB is the file format of Microsoft Access databases built on the Microsoft Jet Database Engine. Jet 3 shipped with Access 97, and Jet 4 with Access 2000 through Access 2003 — so most MDB files you meet today come from that era, or from systems that have kept using the format ever since. A single MDB file can hold many tables at once, together with saved queries, indexes and the relationships between them.

Starting with Access 2007, Microsoft made ACCDB the default format, but MDB never disappeared: legacy business software, archived exports and years of records still live in MDB files. Database Viewer reads both MDB (Jet 3 and Jet 4) and ACCDB directly on your phone.

MDB vs ACCDB: what is the difference?

MDB and ACCDB are both Microsoft Access databases — the difference is the generation. MDB is the older Jet-based format, the default from Access 97 through Access 2003 (Jet 3 and Jet 4). ACCDB became the default with Access 2007 and added capabilities MDB does not have, such as attachment fields and multi-value fields.

For everyday viewing there is nothing to convert: Database Viewer opens MDB and ACCDB side by side on the same on-device engine. A dedicated ACCDB viewer page is coming soon.
