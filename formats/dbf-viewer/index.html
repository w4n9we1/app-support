What is a DBF file?

DBF is the table format that dBASE wrote to disk. dBASE was among the first database programs to reach personal computers, and its II, III and IV generations established what a database file meant for a whole era of business software. The family that grew around it kept the same container: FoxBASE, FoxPro and Visual FoxPro all stored their tables as .dbf, which is why a FoxPro DBF and a dBASE table are near-synonyms in older IT departments.

The structure inside is famously compact: one file, one table. A header block names every field and declares its type — character, numeric, date, logical — after which the records follow back to back, each occupying exactly the same number of bytes. Fixed-length records let a reader jump straight to any row without parsing what came before, which is a large part of why these tables felt instant on hardware that would struggle with a modern spreadsheet.

Text that outgrows its field gets a different home. dBASE-family software marks such cells in the row itself and keeps the long text in a companion memo file — .fpt for the FoxPro line, .dbt for classic dBASE. The table itself reads fine without them; the companion file simply holds the overflow.

Why DBF files are hard to open today

The convenient paths have been closing for years. Modern Excel no longer saves workbooks as DBF, and support for even opening them has been quietly retired from recent releases, so the spreadsheet route leads to a dead end more often every year. Google Sheets and Numbers never read the format at all, and the tools built around DBF have faded from the mainstream — the original Ashton-Tate dBASE line is long gone, and FoxPro's successors serve a niche.

The files, meanwhile, never stopped appearing. Billing systems, membership lists, municipal registers and countless small line-of-business programs written in the dBASE era still run somewhere, and a good number of them write a fresh .dbf on every working day. Add the GIS world, where shapefiles carry a DBF as standard equipment, and the format remains one of the most common things people need to open — without any of the software that used to open it.

DBF in GIS: the shapefile connection

A large share of today's DBF files come from maps. The Esri shapefile, still the default exchange format of the GIS world, is actually a set of files that travel together under one name: .shp holds the geometry, .shx is its spatial index, and .dbf is the attribute table — a perfectly ordinary dBASE table in which each row describes one feature on the map. A parcel's owner, a road's name, a monitoring well's readings: the attributes live in the .dbf, not in the geometry.

That makes the shapefile .dbf the most useful member of the trio to carry on a phone. Copy it from the shapefile folder into Database Viewer and every feature's attributes arrive as a normal, searchable table — no GIS software, no desktop session. The map itself stays behind in the .shp; what you get is the attribute table, read as data.

How to open a DBF file on your phone

Four steps in a single app, and the file never leaves the phone:

  1. Install Database Viewer on the phone: Google Play lists it for Android 8.0 and up, while iPhone owners will find it in the App Store (needs iOS 17.0 or later). Starting is free — installing the app and opening DBF files costs nothing.
  2. Open the .dbf file with the app's Open file button. Android hands you to the system picker, where Downloads, Google Drive or another connected storage location is one tap away. On iPhone, select it from the Files app, which also sees iCloud Drive and folders kept in other cloud services. A .dbf that accompanies a shapefile opens by exactly the same route.
  3. Read the health report that appears first. For a DBF it earns its keep: it confirms the file really is a dBASE table, states which text encoding the records use — DBF predates Unicode, so the code page matters — and flags any damaged region before you start reading.
  4. Browse the table, then export if needed: every row and column is there to scroll, search and sort. When the data has to move, tap Export and pick Table data to write the table out as CSV, or save it as an XLSX workbook; the system save dialog decides where the new file lands. Exporting is included in Pro — a buy-once unlock — while the free tier lets you open the file and preview the data first, so it can be checked before deciding. Text fields are written as plain text; contents that live in companion memo files may not be included.

Need the attributes in a spreadsheet or another system? The export screen can also produce an XLSX workbook, and the MDB to CSV guide walks through the export options in detail.

Frequently asked questions

What is a DBF file?

A DBF file is a database table in the dBASE format — the file type that dBASE II, III and IV wrote on personal computers and that the FoxBASE and FoxPro family kept using afterwards. One file holds one table: a header describes each field (character, numeric, date, logical) and every record below it has the same fixed length. DBF files still turn up in legacy business systems, and every Esri shapefile carries one as its attribute table.

What opens a DBF file nowadays?

Fewer desktop programs than before: dBASE-era tools are discontinued, modern Excel no longer saves DBF files, and web-based spreadsheet services never learned the format. Database Viewer covers the gap on phones — install it, open the .dbf, read its health report and browse the tables with a generous free preview on-device, with no dBASE or FoxPro installation required.

Can Excel still open DBF files?

Increasingly, no. Excel stopped saving workbooks as DBF years ago, and support for opening them has been retired from recent versions too, so the spreadsheet route keeps narrowing. Even where an older copy of Excel still displays one, the file stays trapped on a desktop machine. A dedicated DBF file reader such as Database Viewer handles them on Android and iPhone directly.

Can I view the attribute table of a shapefile?

Yes — the shapefile DBF is the attribute table: a .dbf traveling beside the .shp geometry file, with one table row per map feature. Open that .dbf in Database Viewer and the attributes read like any other table — searchable and sortable on the phone — even though the map itself is not drawn. When the attributes are needed elsewhere, exporting them is part of Pro.

Is the app free?

Yes — the free tier is ad-supported: opening a DBF file, reading its health report and previewing the table all work without paying. Export, together with editing and other extras, is what Pro adds; Pro is bought once and stays yours, with the ads switched off too.

Is my file uploaded anywhere?

Never. The DBF is decoded by a native engine running on the phone itself — no server receives the file, no account is created, and the original opens read-only. Anything you export is written only to the destination you pick in the system save dialog.
