What is a CSV file?

CSV stands for comma-separated values. It records a table as plain text: the top line usually names the columns, and each line below it is one record, with commas marking where one field stops and the next starts. There is no binary layout and no vendor format to decode — only characters that a simple text editor can show.

That plainness is exactly why CSV became the common exchange format for tabular data. Excel, Google Sheets, Numbers, LibreOffice, mainstream database servers, Python and R all import it without plugins, which makes CSV the safest shape for records that need to leave an old Access file and live somewhere new.

What carries over when you convert

An Access database is more than a grid of values, whereas a CSV is precisely that grid — so it pays to know which parts make the trip. Ordinary values come through intact, while binary and OLE cells are written as size placeholders; the machinery Access builds around the data does not make the trip at all.

Carried into the CSV

The table's rows, its columns in their original order and a header row holding the column names. Text, numbers and dates are written out as plain text, so the file opens cleanly in a spreadsheet or loads into another database.

Stays behind in Access

Saved queries, relationships between tables, indexes, forms and reports — Access-specific concepts with no plain-text equivalent, which no converter of any kind can place in a CSV. Attachment and binary fields still appear as columns, but their contents stay behind as placeholders.

Keep in mind, too, that one CSV holds exactly one table. When a database contains several tables you care about, export each of them or bundle them as shown below; ending up with a separate file per table is the normal outcome of any MDB to CSV conversion. How to convert MDB to CSV on your phone

The whole conversion happens inside a single app on the phone already in your pocket:

  1. Install Database Viewer, which Android users get from Google Play (8.0 or newer) and iPhone users from the App Store (iOS 17.0 or newer). Installing it and opening databases costs nothing.
  2. Open the .mdb file with the Open file button. Android shows the Storage Access Framework picker, which reaches Downloads, Google Drive and other storage providers; on iPhone the Files app lists local folders, iCloud Drive and connected cloud services. An .accdb opens through the same route.
  3. Check the health report that appears before any data does. It states whether the database can be read, what text encoding is in use and whether any region is damaged — so you know the export will start from sound data.
  4. Export the table as CSV: select the table, tap Export, choose Table data (CSV), then pick where the file goes in the system save dialog — on the device or a connected location such as Google Drive or iCloud Drive. Export is included in the Pro one-time purchase; on the free tier you can open the database and preview each table first, then decide.

Need every table at once? The export screen can bundle all tables' CSV files into a single ZIP.

CSV or XLSX?

Database Viewer exports to both, and the better pick depends on where the data is heading next. Choose CSV when the file will be imported somewhere — another database, a script, a CRM or a web service — because nearly every system accepts it without fuss. Choose XLSX when the destination is Excel itself and people will simply open the file to read it: the whole database arrives as one ready workbook, a sheet per table, instead of raw text that needs an import step.

Why avoid online MDB converters

Search for an MDB to CSV converter and most results are websites. Underneath, they all work the same way: before producing a CSV, the site needs the entire .mdb on its own server — every table in it, not only the one you wanted. For a database of invoices, patients, members or payroll, that upload is the step worth weighing.

Online converter

The complete database file travels to a third-party server, the conversion runs there and the CSV returns as a download. The uploaded copy sits with the service, and what happens to it next is the service's decision.

Database Viewer — on-device

The engine that reads the database and writes the CSV runs on your phone. There is no upload and no account, the original .mdb is never modified, and the exported file exists only where you choose to save it.

Frequently asked questions

What is a CSV file?

A CSV (comma-separated values) file is a table saved as plain text. Every line is one row, commas divide the fields, and the opening line normally lists the column names. Since it contains nothing but text, practically every spreadsheet, database and programming language can read it.

Can I convert MDB to CSV without Microsoft Access?

Yes. Database Viewer reads MDB and ACCDB with its own native C engine, running on Android and iPhone, so neither a copy of Access nor a Windows PC is involved. Load the database in the app, pick a table and export it as CSV.

Will my tables and columns be preserved?

The data will. An exported table keeps its columns in their original order, gains a header row with the column names and includes every row of values. Attachment and binary fields appear as columns, but their contents stay behind as placeholders; saved queries and relationships are Access constructs that a plain-text format cannot represent, so they are left out.

Can I export to Excel (XLSX) instead?

Yes. Besides CSV, Database Viewer can save the whole database as a single XLSX workbook (a sheet per table) that opens straight in Microsoft Excel, Google Sheets or Numbers. CSV suits importing one table into another system; XLSX suits a file that people will open and read as a spreadsheet.

Is converting free?

Opening the database and previewing its tables costs nothing, in a free tier supported by ads. Exporting to CSV or XLSX belongs to Pro — unlocked by a single one-time purchase that also removes the ads — so you can check that the data is right before paying anything.

Is my database uploaded anywhere?

Never. The conversion runs entirely on your phone: the database is not transmitted to any server, there is no account to create, and the CSV is written only to the location you pick in the save dialog.
