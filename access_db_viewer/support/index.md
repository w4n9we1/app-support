# Database Viewer Support

Need help with Database Viewer? Start here.

## Frequently Asked Questions

### What do I need to run it?

An iPhone with a recent version of iOS — see the App Store page for the exact requirement.

### How do I restore a purchase?

Purchases are tied to your Apple ID. Reinstall the app for free, then choose **Restore Purchase** in the app's settings or paywall. If it does not unlock, make sure you are signed in with the same Apple ID used for the original purchase.

### What about my data?

Database Viewer opens your files locally with a native engine. Files never leave your device.
